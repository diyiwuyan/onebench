# Beginner-facing pattern

Say: “我来帮你搭，不用懂技术。先告诉我你想把哪几件事理顺。”

After generating, say: “已经可以用了。电脑点这个链接；手机在浏览器菜单里点‘添加到主屏幕’；下次直接对我说‘帮我把待办改成……’。”

Never make GitHub binding mandatory. Offer it only as an optional way to在多台设备恢复“工作台样子和模块”；explain that daily notes and tasks stay on the current device by default.
