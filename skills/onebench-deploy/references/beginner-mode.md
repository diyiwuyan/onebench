# Beginner-facing pattern

If the request already contains a role and goal, say: “我来帮你搭，不用懂技术。我先给你做好能直接用的电脑版本。”

Ask “你想把哪几件事理顺？” only when role and goal cannot be inferred.

After verified delivery, use exactly three headings: “电脑怎么打开”“手机怎么添加到桌面”“以后怎么修改”。Omit technical narration.

Never make GitHub mandatory for computer-only use. If phone use was requested, perform the user-owned deployment instead of telling the beginner to configure GitHub. Explain privacy or sync only when their choice is required.
