# 给第一次使用的人

不需要会搭网站，也不需要懂智能体。

## 三步拥有工作台

1. 打开 [OneBench Demo](https://diyiwuyan.github.io/onebench/)，点自己的身份，例如“大学生”或“K12 教师”。系统先把常用模块配好。
2. 默认点击“下载我的本地工作台”：这是一个独立 HTML 文件，放到桌面双击即可使用，不需要注册、部署或联网。
3. 想在手机和多台电脑间同步时，再让智能体升级为“私有仓库同步版”；手机浏览器打开线上版后，选择“添加到主屏幕”。

电脑和手机之间只需恢复工作台配置：在设置里导出 `workspace.json`，另一台设备导入即可。想自动保存配置时，再按引导绑定自己的 GitHub；这不是使用工作台的前提。

## 想让智能体帮忙？

把下面这句话原样发给你正在使用的智能体即可：

> 请按 https://github.com/diyiwuyan/onebench/tree/main/skills/onebench-deploy 的说明，帮我搭一个个人工作台。我是【填写身份】，最想管理【填写一两件事情】。请先给我一个能直接用的版本，技术设置由你处理；最后告诉我电脑和手机各怎么打开。

不会填写身份时，直接说“我是退休教师，想把每天要做的事理清楚”也可以。
