# 给第一次使用的人

不需要会搭网站，也不需要懂智能体。

## 三步拥有工作台

1. 打开 [OneBench Demo](https://diyiwuyan.github.io/onebench/)。点“定制”填写称呼、选择头像和身份；主题、默认模块和示例内容会一起换好，也可以自己增减模块。
2. 点“下载本地版”：会得到一份完整的独立 HTML，放到桌面双击即可使用，不需要注册、部署或联网。
3. 想在手机和多台电脑间使用时，再让智能体升级成你自己账号下的在线版；手机浏览器打开后，选择“添加到主屏幕”。

电脑本地版的数据默认只留在这台电脑的浏览器中。换电脑时可以使用带口令的加密备份。需要多端同步时，智能体会先保留这份本地成品，再为你创建自己的在线项目；只有你明确同意时，才把待办、随手记、头像照片等日常内容放进单独的私有数据仓库。

高级设置里的 GitHub 一键授权需要 OneBench 维护者配置 OAuth 客户端；如果当前版本没有启用授权，使用 Fine-grained token 也可以完成同样的同步。Token 只保存在当前浏览器，不要放进公开仓库。

## 想让智能体帮忙？

把下面这句话原样发给你正在使用的智能体即可：

> 请按 https://github.com/diyiwuyan/onebench/tree/main/skills/onebench-deploy 的说明，帮我搭一个个人工作台。我是【填写身份】，最想管理【填写一两件事情】。请先生成并测试完整本地版；我还要在手机使用，请再部署到我自己的账号。技术设置由你处理，最后只告诉我电脑怎么打开、手机怎么添加到桌面、以后怎么修改。

不会填写身份时，直接说“我是退休教师，想把每天要做的事理清楚”也可以。
