# OneBench 专业版设计来源

OneBench 把现有通用工作台定义为“基础版”。专业版不是简单换主题，而是依据不同人群的高频工作流，分别提供独立的信息架构、首屏、导航和交互。

以下互动数字为 2026-08-01 在小红书网页端登录后看到的公开快照，仅用于说明用户需求强度；数字会随时间变化。OneBench 只借鉴通用界面模式和功能需求，不复制作者头像、图片、文案、题库、教案或品牌素材。

## 版本原则

1. 基础版继续服务第一次使用和通用需求。
2. 专业版拥有独立首屏、导航、数据结构和关键交互。
3. 所有示例条目都能新增、编辑、完成或删除，不把截图中的数据写死成摆设。
4. 专业版仍共享 OneBench 的本地保存、导出、PWA、浏览器新标签页、私有同步和社区贡献能力。
5. 社区新增专业版时必须提交来源说明、桌面与手机截图、交互验收和隐私边界。

## 当前可用交互（2026-08-02）

| 版本 | 已接入的真实数据 | 可直接操作的核心流程 |
| --- | --- | --- |
| 考公冲刺台 | 倒计时、学习待办、行测练习、错题、申论、学习日志 | 修改考试日期；新增／删除练习；自动计算正确率；标记错题二刷；记录申论字数与学习分钟 |
| 班主任工作台 | 学生、成绩、作业、谈话、纪律、座位 | 新增／删除学生；切换关注状态；录入并修改分数；更新交作业人数；记录谈话／纪律；两次点击交换座位 |
| 胡楚靓同款 | 每日计划、灵感、内容项目、作品复盘、备忘录、长期学习 | 增删计划；推进灵感和内容状态；记录作品结论；勾选备忘；累计学习时长 |
| 创作者工作台 | 每日推进、内容管线、发布档期、作品复盘、OKR | 新增选题并推进到制作／发布；修改档期；记录播放与收藏；目标进度加减 |

专业版左下角统一为“设置”。版本切换、返回基础版、称呼、紧凑布局、JSON 数据导入／导出和恢复示例全部放在设置内；首屏和顶栏不再承担版本管理。每个版本使用独立的 `localStorage` 命名空间，旧版本产生的无 ID 条目会在读取时迁移，不会因为升级失去编辑和删除能力。

本地单文件可通过以下参数直接打开指定专业版：

```bash
node scripts/create-local-workbench.mjs --pack civil-service-exam --edition exam --prompt "我要准备国考" --out "我的考公冲刺台.html"
```
