# 作为浏览器新标签页使用

OneBench 可把同一份真实工作台打包成 Chrome 或 Edge 的新标签页扩展。不是另一套精简页面：职业首页、模块市场、任务、记录、番茄钟和复盘都会保留。扩展不申请网站访问权限，工作台配置与日常数据保存在浏览器扩展自己的本地存储中。

## 小白安装（推荐）

1. 打开项目的 [Releases](https://github.com/diyiwuyan/onebench/releases)，下载 `onebench-browser-extension.zip`。
2. 完整解压 ZIP，并把文件夹放在不会移动的位置。
3. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
4. 开启“开发者模式”，点“加载已解压的扩展程序”。
5. 选择包含 `manifest.json` 的解压文件夹，新开标签页完成验收。

当前是开源侧载版，所以浏览器会显示“开发者模式扩展”提示；这是 Chrome／Edge 的侧载机制。未来上架官方商店后才会变成商店一键安装和自动升级。

## 开发者构建

```bash
npm run build:extension
```

构建会检查 Manifest V3、相对资源、图标、版本号、安装说明、文件体积，以及是否误申请网站读取权限。选择 `dist/extension` 文件夹加载即可。

## 更新、数据与权限

- 每次 GitHub 主分支更新都会生成一个经过校验的 Actions 安装包；正式 Release 会把 ZIP 附加到发布页。
- 更新前先在工作台设置中导出备份，再替换原扩展文件并在扩展管理页点“重新加载”。
- 删除扩展可能同时删除扩展本地数据，务必先导出备份。
- 网页、PWA 与扩展使用各自的浏览器本地空间，默认互不自动同步；需要多端一致时启用自己的私有同步。
- 扩展只接管新标签页，不申请读取和修改所有网站、内容脚本或外部连接权限。
