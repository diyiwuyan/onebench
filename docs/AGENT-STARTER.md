# 一句发给智能体

复制下面一段，不需要安装任何东西：

```text
请使用 OneBench 开源方案帮我搭建个人工作台：
https://github.com/diyiwuyan/onebench/tree/main/skills/onebench-deploy

我是【身份】，最想管理【事情】。请先为我生成一份内容完整、功能可操作、放到电脑桌面双击就能使用的工作台，并在浏览器中测试。按我的身份自动配好公共模块和场景模块，我不懂 GitHub、部署和模块，请由你处理。若我还说“需要手机”，再为我创建自己账号下的在线版。完成后只告诉我：电脑怎么打开、手机怎么添加到桌面、以后怎么修改这三件事。
```

【身份】直接填日常称呼即可：大学生、K12 教师、考研、考公、内容创作者、产品／运营、自由职业者或团队负责人。写“学生”也没问题，智能体会默认按大学生模板处理；若不是大学生，请补充年级或学习目标。

【事情】写 1–3 件最希望省心的事即可，例如“课程、作业和考证”“备课和班级通知”“倒计时、真题和错题”“每天的待办和记录”。写“学习”也能用，但多补一个具体事项，生成结果会更贴合。

支持 Skill 的智能体会读取目录中的 `SKILL.md`，并先验收首页、场景模块、保存与离线打开；不支持 Skill 的智能体也能按这段指令使用仓库协议和模板包。只给出临时预览链接、空白卡片页或与 OneBench 不同的自制网页，都不算完成。
